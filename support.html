Requirements

  • iOS or iPadOS 18.
  • A Hermes Agent gateway 0.22.2 or newer, with the API server enabled.
  • The hermes_app plugin for Inbox, attachments, search and QR pairing.

Pairing

Run hermes app pair on the gateway, then scan the code from Connect or the Camera app.

The code carries your gateway URL and API key. Treat it like a password. If you cannot scan it, enter the URL and key by hand.

Common problems

Invalid API key

The gateway answers 401 when the key in the app differs from API_SERVER_KEY on the gateway. Enter the same key, or pair again.

Cannot reach the server

Check the URL scheme and port. Allow local network access for Petasos in iOS Settings. If you use a VPN or a tailnet, make sure it is connected. An HTTPS certificate must be trusted by iOS.

Inbox, attachments or search are missing

The plugin is probably not installed or not enabled. Check with hermes plugins list, then restart the gateway with hermes gateway restart.

No notifications while the app is closed

The App Store build refreshes in the background when iOS allows it. Open the app to catch up.

Reporting

Open an issue at github.com/grabowskil/petasos-site/issues. Include your iOS version, the app version from Settings, and the Hermes version from hermes --version.

Never paste your API key.

Plugin source

The hermes_app gateway plugin is published at github.com/grabowskil/hermes-app-plugin.
