Privacy™

プライバシー / ポリシー

Effective 25 October 2026 · applies to the Petasos iOS app

In short

Petasos has no accounts, analytics, ads or third parties.

It stores your gateway URL and API key on the device.

It sends data only to the gateway you run yourself.

The developer never receives any data.

Who is responsible

Lennart Grabowski develops and publishes Petasos.

Send questions through the support page.

What the app stores on your device

Data Where Notes
Gateway URL App settings, shared with the app's extensions Set by pairing or manual entry.
API key Keychain Set by pairing or manual entry.
Drafts, last-seen notice, tab and filters On the device Stays on the device.
Face ID preference On the device Biometric data never leaves the system.

Deleting the app removes everything it stored.

Disconnect removes the API key.

Where data goes

The app sends every request to the gateway URL you configured, and to no other server.

The gateway receives messages, attachments, approvals and job changes.

With the hermes_app plugin, it also receives a device identifier and search text.

The gateway is your own server. How it handles data depends on how you run it and on Hermes Agent, not on the developer.

The app loads no remote content, fonts or SDKs.

Permissions

  • Camera: scans pairing codes and takes photos for attachments. The app stores nothing from the camera.
  • Local network: reaches your gateway on your network.
  • Notifications: created on the device from gateway data. No developer server sends them.
  • Face ID: optional. Biometric data never leaves the system.

Children

Petasos is not directed at children under 13. It collects nothing.
