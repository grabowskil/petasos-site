What it is

Petasos is an iOS and iPadOS app for a Hermes Agent gateway you run yourself. It talks only to the gateway you pair it with. No account, no cloud in between, no analytics.

Coming to the App Store

Gateway plugin

On your phone

  • Sessions and streaming chat, with tool cards and plan checklists.
  • Approvals from chat or from a notification.
  • Jobs.
  • Host status, toolsets and skills.
  • Inbox, attachments and search.
  • Share sheet and widget.

On your gateway

Install the plugin, restart the gateway and pair the app:

hermes plugins install https://github.com/grabowskil/hermes-app-plugin.git
hermes gateway restart
hermes app pair

Scan the QR code from Connect or the Camera app. The manual URL and key still work. Without the plugin you still get sessions, chat, jobs and host.

Your data stays yours

One gateway URL and one API key live on the device. Everything else lives on your gateway. There is no Petasos server, no telemetry and no account. Read the privacy policy.
